# Chess & Cocoa

> [!IMPORTANT]
> LLM disclosure: This codebase was written with substantial help from large language models: AI coding agents working from the [`AGENTS.md`](AGENTS.md) brief in this repo.

A cozy Android chess game that teaches through play — **concept stage**.
The computer opponent chooses explicit, testable plans, explains the
purpose of its moves, and explains how the human's responses affect those
plans; an established chess engine checks move quality rather than
substituting for the strategic planner.

- [chess_and_cocoa_concept.md](chess_and_cocoa_concept.md) — the product
  concept and technical design brief.
- [chess_and_cocoa_concept_review.md](chess_and_cocoa_concept_review.md) —
  the independent review the brief was revised against.
- `media-sources/` — the icon master (`icon.png`).
